# Интернет-магазин «Web-Larёk»

«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

- **Model** - слой данных, отвечает за хранение и изменение данных.
- **View** - слой представления, отвечает за отображение данных на странице.
- **Presenter** - презентер содержит основную логику приложения и отвечает за связь представления и данных. В данном проекте презентер реализован в файле `main.ts`.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component

Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

**Конструктор:**  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

**Поля класса:**  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

**Методы класса:**  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`

#### Класс Api

Содержит в себе базовую логику отправки запросов.

**Конструктор:**  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

**Поля класса:**  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

**Методы:**  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность.

#### Класс EventEmitter

Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе.

**Конструктор:** `constructor()` - не принимает параметров.

**Поля класса:**  
`_events: Map<string | RegExp, Set<Function>>` - хранит коллекцию подписок на события.

**Методы:**  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется событие.

## Данные

В приложении используются следующие типы данных:

### Интерфейс IProduct

Описывает структуру товара:

- `id: string` - уникальный идентификатор товара
- `description: string` - описание товара
- `image: string` - путь к изображению товара
- `title: string` - название товара
- `category: string` - категория товара
- `price: number | null` - цена товара (null означает, что товар недоступен)

### Интерфейс IBuyer

Описывает данные покупателя:

- `payment: TPayment` - способ оплаты ('card' или 'cash')
- `email: string` - email покупателя
- `phone: string` - телефон покупателя
- `address: string` - адрес доставки

### Тип TPayment

Определяет возможные способы оплаты: 'card' | 'cash'

### Тип TValidationErrors

Тип для ошибок валидации:

- `Partial<Record<keyof IBuyer, string>>` - объект с возможными ошибками для полей покупателя

### Интерфейс IOrder

Описывает данные заказа для отправки на сервер:

- `payment: TPayment` - способ оплаты
- `email: string` - email покупателя
- `phone: string` - телефон покупателя
- `address: string` - адрес доставки
- `total: number` - общая стоимость заказа
- `items: string[]` - массив id товаров в заказе

### Интерфейс IOrderResult

Описывает ответ сервера при оформлении заказа:

- `id: string` - идентификатор заказа
- `total: number` - общая стоимость заказа

### Интерфейс IProductsResponse

Описывает ответ сервера при получении товаров:

- `total: number` - общее количество товаров
- `items: IProduct[]` - массив товаров

## Модели данных

### ProductsModel

Модель для хранения каталога товаров.

**Назначение**: Отвечает за хранение и управление данными о товарах в каталоге.

**Конструктор:** `constructor(protected events?: IEvents)`

**Поля класса:**

- `items: IProduct[]` - приватное поле, массив всех товаров в каталоге
- `selectedProduct: IProduct | null` - приватное поле, товар, выбранный для подробного просмотра

**Методы:**

- `setItems(items: IProduct[]): void` - сохраняет массив товаров в модель, генерирует событие `products:changed`
- `getItems(): IProduct[]` - возвращает массив всех товаров
- `getProductById(id: string): IProduct | undefined` - возвращает товар по его id
- `setSelectedProduct(product: IProduct): void` - сохраняет товар для подробного отображения, генерирует событие `products:selected`
- `getSelectedProduct(): IProduct | null` - возвращает товар для подробного отображения

### BasketModel

Модель для хранения корзины покупок.

**Назначение**: Отвечает за хранение и управление товарами, добавленными в корзину.

**Конструктор:** `constructor(protected events?: IEvents)`

**Поля класса:**

- `items: IProduct[]` - приватное поле, массив товаров в корзине

**Методы:**

- `getItems(): IProduct[]` - возвращает массив товаров в корзине
- `addItem(product: IProduct): void` - добавляет товар в корзину, генерирует событие `basket:changed`
- `removeItem(productId: string): void` - удаляет товар из корзины, генерирует событие `basket:changed`
- `clear(): void` - очищает корзину полностью, генерирует событие `basket:changed`
- `getTotalPrice(): number` - возвращает общую стоимость всех товаров в корзине
- `getItemCount(): number` - возвращает количество товаров в корзине
- `isInBasket(productId: string): boolean` - проверяет наличие товара в корзине по id

### BuyerModel

Модель для хранения данных покупателя.

**Назначение**: Отвечает за хранение и валидацию данных пользователя при оформлении заказа.

**Конструктор:** `constructor(protected events?: IEvents)`

**Поля класса:**

- `payment: TPayment | null` - приватное поле, способ оплаты
- `email: string` - приватное поле, email покупателя
- `phone: string` - приватное поле, телефон покупателя
- `address: string` - приватное поле, адрес доставки

**Методы:**

- `setData(data: Partial<IBuyer>): void` - сохраняет данные покупателя, генерирует событие `buyer:changed`
- `getData(): IBuyer` - возвращает все данные покупателя
- `clear(): void` - очищает все данные покупателя, генерирует событие `buyer:changed`
- `validate(): TValidationErrors` - проверяет валидность всех данных покупателя
- `validateOrder(): { valid: boolean; errors: string }` - проверяет валидность полей заказа (оплата и адрес)
- `validateContacts(): { valid: boolean; errors: string }` - проверяет валидность контактов (email и телефон)

## Слой коммуникации

### WebLarekApi

Класс для работы с API сервера Веб-Ларёк. Наследуется от базового класса `Api`.

**Назначение**: Отвечает за получение данных с сервера и отправку заказов.

**Конструктор:** `constructor(baseUrl: string, options: RequestInit = {})`

**Методы:**

- `getProducts(): Promise<IProductsResponse>` - получает список всех товаров с сервера (GET /product)
- `postOrder(order: IOrder): Promise<IOrderResult>` - отправляет заказ на сервер (POST /order)

## Слой представления (View)

### Класс Modal

Компонент модального окна.

**Конструктор:** `constructor(container: HTMLElement, protected events: IEvents)`

**Методы:**

- `open(): void` - открывает модальное окно
- `close(): void` - закрывает модальное окно, генерирует событие `modal:closed`
- `render(data: { content: HTMLElement }): HTMLElement` - отображает контент в модальном окне и открывает его

### Класс Card

Компонент карточки товара. Поддерживает три режима: 'catalog', 'preview', 'basket'.

**Конструктор:** `constructor(container: HTMLElement, protected events: IEvents, protected type: 'catalog' | 'preview' | 'basket')`

**Сеттеры:**

- `id: string` - устанавливает идентификатор товара
- `title: string` - устанавливает заголовок
- `price: number | null` - устанавливает цену
- `category: string` - устанавливает категорию и соответствующий CSS-класс
- `image: string` - устанавливает изображение
- `description: string` - устанавливает описание (для режима preview)
- `index: number` - устанавливает порядковый номер (для режима basket)
- `buttonText: string` - устанавливает текст кнопки

**Методы:**

- `disableButton(disabled: boolean): void` - блокирует/разблокирует кнопку

**Генерируемые события:**

- `card:select` - при клике на карточку в режиме catalog
- `card:toggleBasket` - при клике на кнопку в режиме preview
- `basket:remove` - при клике на кнопку удаления в режиме basket

### Класс Basket

Компонент корзины.

**Конструктор:** `constructor(container: HTMLElement, protected events: IEvents)`

**Сеттеры:**

- `items: HTMLElement[]` - устанавливает список товаров
- `total: number` - устанавливает общую сумму
- `disabled: boolean` - блокирует/разблокирует кнопку оформления

**Генерируемые события:**

- `basket:order` - при клике на кнопку оформления

### Класс OrderForm

Компонент формы заказа (первый шаг).

**Конструктор:** `constructor(container: HTMLElement, protected events: IEvents)`

**Сеттеры:**

- `address: string` - устанавливает адрес
- `payment: TPayment` - устанавливает способ оплаты и визуальное выделение кнопки
- `errors: string` - устанавливает текст ошибки
- `valid: boolean` - активирует/деактивирует кнопку "Далее"

**Генерируемые события:**

- `order:changeAddress` - при изменении адреса
- `order:changePayment` - при выборе способа оплаты
- `order:submit` - при отправке формы

### Класс ContactsForm

Компонент формы контактов (второй шаг).

**Конструктор:** `constructor(container: HTMLElement, protected events: IEvents)`

**Сеттеры:**

- `email: string` - устанавливает email
- `phone: string` - устанавливает телефон
- `errors: string` - устанавливает текст ошибки
- `valid: boolean` - активирует/деактивирует кнопку "Оплатить"

**Генерируемые события:**

- `contacts:changeEmail` - при изменении email
- `contacts:changePhone` - при изменении телефона
- `contacts:submit` - при отправке формы

### Класс Success

Компонент сообщения об успешном заказе.

**Конструктор:** `constructor(container: HTMLElement, protected events: IEvents)`

**Сеттеры:**

- `total: number` - устанавливает сумму списания

**Генерируемые события:**

- `success:close` - при клике на кнопку закрытия

### Класс Page

Компонент основной страницы.

**Конструктор:** `constructor(container: HTMLElement, protected events: IEvents)`

**Сеттеры:**

- `counter: number` - устанавливает счетчик товаров в корзине
- `catalog: HTMLElement[]` - устанавливает каталог товаров

**Генерируемые события:**

- `basket:open` - при клике на иконку корзины

## Презентер

Презентер реализован в файле `src/main.ts`. Он выполняет следующие функции:

1. **Инициализация**: создает экземпляры всех моделей, компонентов представления и API.
2. **Загрузка данных**: получает товары с сервера и сохраняет их в модель.
3. **Обработка событий**: подписывается на все события от моделей и компонентов представления.
4. **Синхронизация данных и представления**: при изменении данных обновляет соответствующие компоненты.

### Основные события и их обработка:

| Событие                | Источник       | Действие презентера                                             |
| ---------------------- | -------------- | --------------------------------------------------------------- |
| `products:changed`     | ProductsModel  | Обновляет каталог на главной странице                           |
| `card:select`          | Card (catalog) | Открывает модальное окно с детальной карточкой товара           |
| `card:toggleBasket`    | Card (preview) | Добавляет/удаляет товар из корзины                              |
| `basket:changed`       | BasketModel    | Обновляет счетчик и содержимое корзины                          |
| `basket:open`          | Page           | Открывает модальное окно с корзиной                             |
| `basket:order`         | Basket         | Открывает форму заказа                                          |
| `order:changeAddress`  | OrderForm      | Сохраняет адрес в BuyerModel                                    |
| `order:changePayment`  | OrderForm      | Сохраняет способ оплаты в BuyerModel                            |
| `order:submit`         | OrderForm      | Открывает форму контактов                                       |
| `contacts:changeEmail` | ContactsForm   | Сохраняет email в BuyerModel                                    |
| `contacts:changePhone` | ContactsForm   | Сохраняет телефон в BuyerModel                                  |
| `contacts:submit`      | ContactsForm   | Отправляет заказ на сервер, очищает корзину и данные покупателя |
| `success:close`        | Success        | Закрывает модальное окно                                        |
| `modal:closed`         | Modal          | Закрывает модальное окно                                        |

## Событийная модель

### События моделей данных:

- `products:changed` - изменение каталога товаров
- `products:selected` - изменение выбранного для просмотра товара
- `basket:changed` - изменение содержимого корзины
- `buyer:changed` - изменение данных покупателя

### События представлений:

- `card:select` - выбор карточки для просмотра
- `card:toggleBasket` - нажатие кнопки покупки/удаления товара
- `basket:remove` - нажатие кнопки удаления товара из корзины
- `basket:open` - нажатие кнопки открытия корзины
- `basket:order` - нажатие кнопки оформления заказа
- `order:changeAddress` - изменение адреса в форме
- `order:changePayment` - изменение способа оплаты
- `order:submit` - нажатие кнопки "Далее"
- `contacts:changeEmail` - изменение email
- `contacts:changePhone` - изменение телефона
- `contacts:submit` - нажатие кнопки "Оплатить"
- `success:close` - закрытие окна успеха
- `modal:closed` - закрытие модального окна

## Функциональные требования

### Главная страница:

- Содержит каталог товаров
- При нажатии на карточку товара открывается модальное окно с информацией о товаре
- При нажатии на иконку корзины открывается корзина
- На иконке корзины отображается счетчик количества товаров

### Просмотр товара:

- Показана детальная информация о товаре
- Кнопка «В корзину» / «Удалить из корзины» в зависимости от наличия товара в корзине
- Если у товара нет цены, кнопка заблокирована с текстом «Недоступно»

### Корзина:

- Отображается список выбранных товаров
- Для каждого товара указана цена и кнопка удаления
- Отображается общая стоимость
- Если корзина пуста, кнопка оформления деактивирована
- При нажатии «Оформить» открывается форма заказа

### Оформление заказа:

- **Шаг 1:** выбор оплаты, ввод адреса, валидация, кнопка «Далее»
- **Шаг 2:** ввод email и телефона, валидация, кнопка «Оплатить»
- После успешной оплаты показывается сообщение, корзина очищается

### Модальные окна:

- Закрываются по клику вне окна или на крестик
- Не скроллятся при открытии
